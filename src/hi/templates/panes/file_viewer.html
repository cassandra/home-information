{% load icons %} {% load device_tags %} {% comment %} In-app file viewer overlay, rendered once per page by the file_viewer_shell tag. Behavior lives in js/file-viewer.js, which reads the data-file-viewer-* hooks below: it shows one region at a time, fills the slots, and acts on the actions. It never builds markup. Kind regions are named by FileViewerKind external names; "loading", "error" and "pdf-unsupported" are viewer states. PDF pages are rendered by js/file-viewer-pdf.js into clones of the page template, one per page. Open-in-new-tab links get the file's URL on open; like any external link, they need browser_nav, and device.js explains when it is missing. {% endcomment %}
